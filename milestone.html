Link a File

Keep Milestone's data in a plain JSON file on your disk — in a folder synced by iCloud Drive/OneDrive/Dropbox, it becomes a simple way to share this project across your own devices.

My file isn't syncing across devices
Make sure the file lives inside a folder your cloud provider (iCloud Drive, OneDrive, Dropbox, …) actually syncs — picking a file only stores it locally. Milestone rereads it every 45s and on every save, and merges changes so two devices editing at once won't lose work.

Help

The basics
Add tasks with the + Add Task button. Each task has a start/end date, a % complete, and can be a milestone (a zero-duration diamond). Use Indent/Outdent to build a work breakdown structure — a parent task's own dates and progress roll up automatically from its children.
Task Mode
Every task is either Manually Scheduled (pushpin) or Auto Scheduled (chart icon) — click the icon in the Task Mode column, or use the Task Mode field in a task's dialog. An Auto task follows its predecessors and constraints. A Manual task stays exactly where you put it: predecessors never move it, its Start, Finish and Duration can be free text such as "TBD", and a warning triangle appears if it starts earlier than its predecessors allow. Manual tasks are drawn with a dashed bar, and are left out of the critical path. Switching a task to Auto moves it to the earliest date its links allow. The "New tasks" button at the right of the toolbar chooses the mode new tasks start in (Manual, like MS Project, by default).
Dependencies
Open a task and add a predecessor to link it to another task (Finish-to-Start, Start-to-Start, Finish-to-Finish or Start-to-Finish). Give it a lead or lag in days: a positive number delays the dependent task (lag), a negative number lets it overlap and start early (lead) — e.g. "3FS+2" waits 2 extra days after task 3 finishes, "3FS-2" starts 2 days before task 3 finishes. Moving a task forward automatically pushes any dependent tasks forward too — it never pulls a task earlier on its own. A circular dependency is flagged with a warning icon and stops auto-scheduling for the tasks involved.
The Gantt chart
Drag a bar to reschedule it, drag its edges to resize, or drag the small circle on its right edge onto another task to create a dependency. Click a bar or row to edit it. The route icon in the toolbar highlights the critical path — the chain of tasks with zero slack that determines the overall project end date.
Data & sync
Everything lives in this browser's local storage — nothing ever leaves your machine unless you export it or link a file. Data → Export/Import moves a full JSON snapshot in or out; Local Backups keeps a rolling daily snapshot. The file-link button next to Data lets you sync to a plain JSON file, which works well inside an iCloud Drive/OneDrive/Dropbox folder for keeping your own devices in step.
Nothing here ever leaves your machine unless you explicitly export or link a file.
