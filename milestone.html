How this works

Durations, lags and dependencies count working days only — weekdays that work and are not a holiday. Auto Scheduled tasks start and finish on working days; Manually Scheduled tasks keep the dates you give them. Days off are shaded in the Gantt chart. Public-holiday presets are a starting point — check them against your own calendar; regional and company days differ. Dates already in the plan are not moved when you change this, and other plans keep their own calendar.

Help

Building a plan
Add Task inserts a task below the selected one, or at the bottom when nothing is selected. Each task has a start and end date and a % complete, and can be a milestone (a one-day diamond).
Right-click a task (in the list, or its row in the chart) for a menu with Edit, Add task, Add empty line, Duplicate, Copy, Cut, Paste, Indent, Outdent and Delete. Right-clicking on the empty part of the list offers Add task, Add empty line and Paste. The buttons for the selected tasks (Edit, Duplicate, Copy, Delete) appear in the toolbar while something is selected; with one task Edit opens the same dialog as a double-click.
Row colour (in the task dialog, or under Edit for several tasks) marks a task in the list with a stripe at its left edge and a light tint of the same colour — also behind its bar in the Gantt chart, and in the printout and the Excel export. The bars themselves keep their status colours: green complete, red late, blue in progress, grey not started.
Add empty line (in the menu next to Add Task, or on the right-click menu) inserts a blank row below the selected task (below its whole block when it is a group) to separate blocks of tasks. It has an ID but no name, dates or WBS, is never scheduled, charted or linked, and can be moved, indented, copied and deleted like any row.
Indent and Outdent build the work breakdown structure. A parent task's own dates and progress roll up from its sub-tasks, and its WBS code (such as 2.1.3) follows the outline.
Drag a task's line up or down to reorder it — a parent brings its sub-tasks along.
Duplicate (on a task's line, in the toolbar once a task is selected, or on the right-click menu) makes an exact copy right below it, including all its sub-tasks and their sub-tasks. Undo takes it back.
The double arrow above the ID numbers steps through the outline: collapse every group, then open the first level, then the next level, and so on until everything is open — then it starts over.
Selecting several tasks
Ctrl/Cmd+click adds a task to the selection or takes it out; Shift+click selects every visible row from the last one you clicked; Ctrl/Cmd+A selects all visible tasks; Esc (or the “N selected” chip in the toolbar) clears it.
Indent, Outdent, Clone, Copy and Delete then act on all of them (a group brings its sub-tasks). The Edit button in the toolbar opens the full task dialog for one selected task (the same as a double-click) and, with several selected, Edit tasks: tick the fields to change — % complete, Resource, Task Mode, Row colour, Move dates by a number of working days, Add predecessor, and any custom field you show — and Apply. It is one Undo step.
Copy and paste
Ctrl/Cmd+C (or the copy button) copies the selected tasks with their sub-tasks and the links between them; Ctrl/Cmd+V pastes them below the selected task at its level — into this plan or another. Ctrl/Cmd+X cuts.
The same copy is a table Excel understands: a header row, the ID column and the columns you show, names indented by level.
It works the other way too: copy rows in Excel — with a header such as Task Name, Start, Finish, Duration, % Complete, Resource, Predecessors — and paste them here. Indented names or a WBS / Outline Level column give the outline; dates like 07.09.2026, durations like 5 days and links like 3FS+2 are read, and “TBD” dates make a Manually Scheduled task.
Find a task
Ctrl/Cmd+K, / or the Find button opens a search: part of a name (every word must match), a WBS code such as 2.1, #12 for the task with that ID, or @anna for a resource, and status:late for the late tasks (also complete, future, on for on schedule — combine it with words). Enter goes to the task — folded groups open, a filter that would hide it steps aside, the row (and in the Gantt view the bar) scrolls into view and flashes. Shift+Enter shows only the matches.
Undo and redo
The two round arrows at the left of the toolbar take back and repeat your changes one step at a time — an edit together with everything it moved in the schedule, an added or deleted task, a baseline, a change of the working calendar. The toast says what was undone and offers the opposite step.
The history is kept in memory only: it starts empty when you open the app or switch to another plan, and it is cleared when changes from another device are merged in — so undo can never take back somebody else's work.

Task Mode
Auto Scheduled (chart icon) tasks follow their predecessors and constraints.
Manually Scheduled (pushpin) tasks stay exactly where you put them: predecessors never move them, their Start, Finish (a manual milestone's too) and Duration can be free text such as “TBD”, and a warning triangle appears if one starts earlier than its predecessors allow. They are drawn with a dashed bar and left out of the critical path.
Click the icon in the Task Mode column (or use the Task Mode field in a task's dialog) to switch. Switching to Auto moves the task to the earliest date its links allow. New tasks are in the menu next to Add Task sets the mode a newly added task gets — Auto Scheduled by default.
Dependencies
Open a task and add a predecessor to link it to another task: Finish-to-Start, Start-to-Start, Finish-to-Finish or Start-to-Finish. In the list you can type them directly, the way MS Project writes them: 3, 3FS, 3SS+2d, 4FF-1w, several separated by , or ;.
Lag and lead: a positive number delays the dependent task, a negative number lets it overlap and start early. 3FS+2 waits 2 extra days after task 3 finishes; 3FS-2 starts 2 days before task 3 finishes. Units are days (d), weeks (w) or hours (h), all counted in working days; elapsed (ed) and percentage lags are not supported.
A circular dependency is flagged with a warning icon and stops auto-scheduling for the tasks involved.
Automatic scheduling, as in MS Project
An Auto task always sits at the earliest date its links allow. Move a predecessor later and the dependent tasks are pushed later; make it shorter, finish it early (record an Actual Finish) or delete it, and they are pulled earlier.
A date you choose is kept. Type a Start later than its links allow (or drag the bar later, or change it in the task's dialog) — a deliberate delay — and the task stays there with a Start No Earlier Than constraint at that date; a later Finish gets Finish No Earlier Than. Links can still push the task later, but never pull it before that date.
A date that is not a delay adds no constraint: a milestone or a task with no links stays a plain as-soon-as-possible task. Change or remove a constraint in the task's dialog. Manual tasks and tasks that have already started are never moved.
Working calendar
Each plan has its own working days — Monday to Friday unless you change it (Schedule menu → Working calendar…). Durations, lags and dependencies count working days only: a 5-day task that starts on a Monday finishes on that Friday, and its successor starts the next Monday.
Scheduling precision (Schedule menu → Scheduling precision…, its own dialog): the standard is whole days, but a plan can switch to Hours & minutes — like MS Project — so tasks can start and finish at a time of day. Set the working day's start/end and its breaks there too; date fields, Duration (type "4h" or "90m") and the columns adapt once it's on. Switching in keeps a task spanning its whole day; switching back just drops every time.
In an Hours & minutes plan the chart gets an Hours scale (20 px an hour, the day over its 24 hours; nights, the lunch break and days off are shaded). Drag a bar, or its edges, in 15-minute steps: an Auto task lands on working time (a move into the lunch break comes out after it), a Manual task goes exactly where you drop it, and linked tasks follow.
In the list, click a Start, Finish or Actual cell and type date and time (07.09.2026 14:30) — a date alone keeps the time, a time alone (14:30) keeps the date. The Duration cell takes 4h, 90m, 2d or 1w. The Excel Gantt sheet gets one column per working hour.
Add holidays and other days off in the same dialog: a single day, a longer break (from … to …), or a day that comes back every year, each with an optional name. They count as days off exactly like weekends, and are shaded in the Gantt chart.
Public holidays: pick a country or region (Germany with each of its states, Austria, Switzerland, the UK, Ireland, the US, Canada, France, the Netherlands, Belgium, Spain, Italy) and the years, then Add public holidays. Movable ones (Easter, Ascension, Thanksgiving …) are worked out for each year; days that fall on a day off anyway are left out.
Treat the presets as a starting point: check them against your own calendar — regional and company days differ — and edit or remove any entry.
Auto tasks start and finish on working days — a date you type or drag to on a day off moves to the nearest working day. Manual tasks keep exactly the dates you give them. Changing the calendar or the holidays never moves dates that are already in the plan.
Actual dates and status
Actual Start and Actual Finish record what really happened, and they are the schedule: an Actual Start becomes the task's Start (a running task keeps its duration, so its Finish moves with it) and an Actual Finish becomes its Finish. The tasks that depend on it are re-planned from those dates — later or earlier.
Click the % cell of a task to type its % complete (0–100; 50 or 50%). A group's % is worked out from its sub-tasks, so it is not editable.
Recording an Actual Finish marks the task 100% complete and fills an empty Actual Start. A task that has started or finished is not rescheduled any more; a warning triangle appears if its predecessors say it couldn't have started yet.
A group shows the actual dates of the tasks in it: the earliest actual start, and an actual finish once everything in it has finished.
Remaining Duration (the duration still to go, from % complete) and Status (Complete, On Schedule, Late or Future Task, judged against today) are worked out for you.
Baselines and variance
The bar is the current schedule. To keep the original plan, set a baseline (Schedule menu → Baseline…): a frozen copy of every task's Start and Finish, only ever taken when you ask. Keep up to eleven — Baseline and Baseline 1–10 — and choose which one to compare with.
The baseline shows as a thin grey line under each bar in the Gantt chart (the ruler button hides it).
The Start Variance, Finish Variance, Baseline Start/Finish/Duration and Duration Variance columns show how far each task has moved, in working days (working minutes for a leaf task in an Hours & minutes plan) — positive means later than the baseline.
Reschedule remaining work… (Schedule menu) catches the plan up with a status date you choose: an overdue task moves there, an in-progress task keeps its remaining work from that date if it would otherwise finish later. Finished tasks and tasks ahead of schedule are left alone.
Columns
Click Columns in the toolbar to tick the columns you want and reorder them. The Tasks view and the Gantt view each remember their own set on this device; Task Name always stays.
Remaining Duration, Resource, the baseline and variance columns and the custom fields start hidden. Click a Resource or actual-date cell to edit it, or use the task dialog.
Custom fields
Every task can carry fields of your own — text, numbers, dates and yes/no ticks (up to five of each). Add field on the task dialog's Custom fields tab (or Manage custom fields… under Columns) creates one; the tab shows only the fields you use. Fill them in on that tab or — once ticked under Columns, where they start hidden — straight in the list (click a cell; a flag toggles).
In Manage fields you name, rename and remove fields (removing one deletes its values; Undo brings them back). The names are saved with the plan, so another plan can use its own. Custom fields can be filtered like any column and are included in the Excel export.
Filtering
Click the funnel in a column header (every column has one) for an Excel-style filter. Dates get rules — equals, before, after, between, or relative to today such as this week, next month or year to date — and a Year › Month › Day list. Text columns get contains / begins with / ends with / equals and their negatives; numbers get equals, greater or less than, and between.
Every column also has a list of its values to tick, with a search box and (Blanks) for tasks that have no value.
Filters on several columns combine, so a task must match all of them. A group stays visible while any sub-task inside it matches, and stays open while a filter is on.
The bar under the toolbar shows what is filtered and how many tasks are showing; click × on a chip, or Clear all, to remove it. Filters are only for looking — they aren't saved, and a task you add or edit stays visible until you filter again.
The view
The left side is the same task list as in the Tasks view — the same filters, editing and buttons — with the chart to its right. Drag the thin strip between them to change how much room the list gets. It scrolls sideways when it has more columns than fit, and its ID … Task Name columns stay in place.
The Week / Month / Year buttons change the scale. Year (the default) shows quarters; Week is labelled by calendar week (CW — weeks start on Monday, ISO 8601). Days off are shaded.
Working with bars
Drag a bar to reschedule it and drag its edges to resize it. Click a bar or a row to edit it.
Drag the small circle on a bar's right edge onto another task to create a dependency.
The ruler button shows or hides the baseline line under the bars.
Printing
Print / PDF… (the Data menu, or Ctrl/Cmd+P) lays the list and the chart out on pages of the paper you choose — A4, A3, Letter, Legal or Tabloid, landscape or portrait. The whole timeline is fitted to the page width, long plans continue on the next page with the heading repeated, and a live preview shows every page.
Choose the list columns, the time range, the timescale (weeks, months or quarters — automatic by default), and whether to show the baseline, the critical path, dependency arrows, the today line and days off. Tasks print as the list shows them (folded groups and filters apply) unless you expand every group. In your browser's print dialog choose Save as PDF for a file.
Critical path
The route icon in the toolbar highlights the critical path — the chain of tasks with no float left that determines the project's finish. It follows the real schedule and all four link types with their lags and leads, counted in working days. Manual tasks and summary tasks are left out.
Plans
Each plan has its own tasks, its own daily backups and its own linked file, so switching plans also switches which file is kept in sync. Deleting a plan only removes it from this browser; its file is never touched.
Files and sync
Every plan is kept as a plain JSON file in a folder on your disk (choosing the folder is required, in Chrome/Edge). Every change is saved to it automatically, and in an iCloud Drive, OneDrive or Dropbox folder it keeps your own devices in step. New plan and Duplicate ask for the folder; Open plan from folder… opens a plan file that is already there.
Conflicted copies. When two devices save at once, OneDrive or Dropbox keeps one file and renames the other (plan-DESKTOP-4F2.json, plan (1).json, plan_PC.json). Because Milestone sees the whole folder it merges them in — the newer version of each task wins — and renames them merged_…. Nothing is deleted; the merge is listed for review. A plan linked to a single file (from an older version) shows a Link folder reminder next to the file button.
Daily backups. The first time you open a plan or save it each day, Milestone also writes a dated snapshot into a Backups subfolder of its linked folder — one file per day, kept forever. It never overwrites what is already there for the day.
You can disconnect a plan (click the “Linked” button at the top right, or use the plan menu) — the file is kept, and Milestone asks you to choose a folder straight away. Hover the button to see which file the plan is linked to. If the file is moved or deleted, Milestone asks you to pick another file in the same folder or create a new one. Chrome does not allow Desktop, Documents or Downloads themselves as the folder — pick one inside them.
Working together on one file
When several people (or devices) use the same linked file, Milestone reads the file before it writes, so a save never wipes out someone else's work. Changes to different things — even different fields of the same task — are all kept.
If you and someone else changed the same field, the newer edit is kept and an amber conflicts badge appears next to the file name: click it to see both versions and take the other one if it should have won. Tasks that depend on something that moved are re-planned after a merge.
Import, export and backups
Data → Export / Import moves a full JSON snapshot of the current plan out or in.
Export to Excel saves a formatted .xlsx workbook: a task list plus an optional Gantt chart sheet, each sheet using the columns you chose in its own view.
Import MS Project XML / CSV… reads a plan saved from MS Project as XML (File → Save As → XML Format): tasks and their outline, dates, % complete, actual dates, links with lags, manual mode, constraints, resources, baselines, the working week and the holidays. A file with real times of day switches the plan to Hours & minutes scheduling too (when "Import working calendar" is ticked), recovering the working hours and breaks from it.
Export MS Project XML (Data menu) saves the whole plan as a .xml file that MS Project opens: File → Open, file type “XML Format”. Outline, dates, durations, links with lag, constraints, actual dates, baselines, resources, the working week and holidays go along, each task's real time of day included for an Hours & minutes plan; empty lines are left out, and custom-field values and TBD dates go into the task’s Notes.
It also reads a CSV with a header row — English or German column names such as Task Name, Start, Finish, Duration, Predecessors, Outline Level. A preview shows what was found; you add the tasks to this plan or replace its tasks (a backup file is downloaded first).
Print / PDF… is under Data as well — see the Gantt chart topic.
Local Backups keeps a rolling daily snapshot of every plan in this browser.
Nothing here ever leaves your machine except into the files you choose.
